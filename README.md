# 🏥 Medical Appointment Booking

## 📌 Project Description
**Medical Appointment Booking** is a web-based healthcare platform that allows patients to easily schedule and manage medical appointments. It helps improve access to healthcare services and streamlines communication between patients and doctors.

## 🚀 Features
- 👤 User Registration & Login  
- 🏥 Doctor Search & Listing  
- 📅 Appointment Booking & Management  
- 🔔 Notifications & Reminders  
- ✍️ Reviews System  
- 🖥️ Profile Management  

## 🛠️ Technologies Used
- HTML  
- CSS  
- React.js  
- JavaScript
