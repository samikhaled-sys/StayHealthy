# StayHealthy

## 📌 Project Description
StayHealthy is a web-based healthcare platform designed to help patients connect with doctors anytime and from anywhere. It focuses on improving access to healthcare services in remote and underserved areas.

## 🚀 Features
- User Registration (Sign Up)
- User Login Authentication
- Doctor Search
- Appointment Booking
- Reviews System
- Profile Management

## 🛠️ Technologies Used
- HTML
- CSS
- React.js
- JavaScript
